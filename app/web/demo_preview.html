离线架构与答辩防翻车设计

1. 全栈本机无密钥推理：
OCR 采用本地 PP-OCRv5 + 繁体 PP-OCRv3 ONNX 双模型；语义向量采用本地 bge-small-zh-v1.5（512 维）；问答生成支持本机 Ollama，无外部云 API 依赖。
2. 构造性 100% 可溯源：
所有展示的方剂单元格、三元组及问答引文，均经过 Block.text[start:end] 逐字相等校验，携带 source_hash 与像素级 bbox。
3. 现场异常优雅降级：
大模型未启动时自动退回原文段落摘录模式；图像格式异常或双行小字模糊时明确标示「待核」，绝不静默伪造数据或白屏报错。
