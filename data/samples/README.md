# 古籍页样本目录（占位）

> **命题单位脱敏样本仅限赛事研发使用，不得外传。**
> 本目录当前**不含任何真实古籍扫描页**，仅有本说明文件。

## 合规义务

- 样本仅用于本次赛事的研发、调试与本地评测，不得复制、转授、公开发布或上传至任何外部服务（含云端模型、在线 OCR、网盘、代码托管平台）。
- 演示录屏 / 截图 / 报告若包含脱敏样本，须由参赛者自行复核后再对外提交。
- 样本接收、使用、销毁须登记；赛事结束后按命题单位要求处置。
- 真实扫描页、PDF 与影像文件已列入 `.gitignore`（`data/samples/*.png|jpg|jpeg|tif|pdf`），**不得提交进仓库**。

## 到位后须补齐的登记信息

每批样本建一个 `来源登记.md`（该文件可进仓库，仅含元数据、不含影像）：

| 字段 | 说明 |
|---|---|
| 批次编号 | 如 `S2026-001` |
| 来源与授权依据 | 命题单位提供方式、授权文件编号、获取日期 |
| 脱敏范围 | 已去除的馆藏章、批注者姓名、编号等 |
| 页数 / 格式 / 分辨率 | 便于复现 OCR 预处理 |
| 版本与年代信息 | 影响异体字 / 通假字映射策略 |
| 保管人 / 销毁日期 | 保密义务闭环 |

## 命名规范（建议）

```
S2026-001__p0001.png       # 批次__页码
S2026-001__p0001.meta.json # 页面级元数据（尺寸、DPI、方向）
```

页面 ID 由 `ocr/pipeline.py:new_page_id()` 生成，样本批次号作为前缀写入 `page_id` 或 `source_hash` 的来源片段，保证可溯源。
