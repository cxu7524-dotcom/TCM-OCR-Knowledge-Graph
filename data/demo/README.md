# 示例数据（合成示意 · 非真实古籍）

> **示例数据 / 模型未接入。**
> 本目录内容全部为**人工编写的合成示意文本**，不是真实古籍扫描页、不是古籍原文，
> 不含真实影像、不含患者信息，**禁止作为评测结果或诊疗依据**。

## 文件

| 文件 | 内容 |
|---|---|
| `demo_page.json` | 一张示意古籍页的 OCRResult：10 个带 bbox / line_id / quote / source_hash 的竖排文本块 |
| `demo_questions.json` | 8 个示例问题：`expect=answer`（原文有依据）、`expect=refuse`（无依据或越界，必须拒答） |
| `README.md` | 本说明 |

实体、三元组与图谱**不写在文件里**：由 `extract/rules.py` 的确定性规则从示意文本现场产出，
再经 `graph/build.py` 构图，这样四步链路的每一环都真的在跑代码，而不是回放静态结果。

## 使用方式

- 界面：步骤一点击「加载示例古籍页」。
- 接口：`POST /api/pages`（表单 `demo=1`）。
- 报告：`python eval/run_all.py` 的「链路自检明细」段落。

## 明确的边界

- 所有桩输出在界面、接口响应、评测报告里都带 `is_demo=true` / `model_loaded=false` / `badge=示例数据 / 模型未接入`。
- `extract/evaluate.py` 与 `eval/metrics.py` 会显式排除 `is_demo=True` 的记录，**示例数据不参与任何计分**。
- 五项指标（CER / 字段 F1 / 表格结构还原 / 可溯源率 / 拒答率）当前一律「待测」；
  链路自检里的通过 / 拒答条数是**调试明细**，不是可溯源率或拒答率。
- 页面常驻免责声明：**仅供参考、非诊疗建议**。
