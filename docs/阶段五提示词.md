## 3. 指标口径修正（本阶段起生效）

| 指标 | 口径 | 说明 |
|---|---|---|
| CER | 编辑距离 / GT 字数，按页加权 | 不变 |
| 覆盖率 | pred 中能在 GT 内匹配的字数 / pred 长度 | 不变 |
| **列数准确率** | 切出的列数 / 人工数的真实列数（抽样 10 页，误差 ≤ ±2 列算对） | **替代「块数」** |
| **列内字数比** | 识别字数 / 该页 GT 字数 | 替代「块数」，衡量漏读 |
| 跨列框率 | 一个框横跨 ≥2 列的框数 / 总框数（抽样 10 页人工判定） | 新增，直接对应截图问题 |

**停用「块数中位 > 60」**。上一轮据此判「未达标」是口径错误，本阶段报告需说明该指标作废。

## 4. P0 查合成集 F1 回归（最高优先）

1. **拿对照**：`TCM_OCR_VERTICAL_SPLIT=0 python eval/run_all.py --refresh` 跑一遍，得到「关闭逐列」的 F1；
   再 `TCM_OCR_VERTICAL_SPLIT=1` 跑一遍。两次都保留 `extraction_predictions.jsonl`（分别另存）。
2. **定位差异**：逐条对比两份预测，按 `type` 分组统计 TP/FP/FN 变化，找出「修前抽到、修后抽不到」的实体。
3. **追到块级**：对被丢掉的实体，检查它所在 Block 的 `text / text_norm / kind / line_id / reading_order`，
   判断是下列哪一种：
   - 逐列模式把跨行主语切断（`line_id` 变化导致 `extract/rules.py` 的跨行规则失效）
   - 逐列模式改变了 `kind`（如把段落标成 `annotation`），被规则过滤
   - 整页兜底与逐列的 block 顺序不同，规则依赖「前一行」时错位
4. **修根因**：优先修抽取规则对块结构的依赖（让规则不依赖绝对顺序，改用 `bbox` 相对位置或同列判定）；
   不要为了 F1 去放宽抽取口径。
5. **验收**：F1 ≥ 0.6471（回到阶段三水平），且 CER 不高于 0.0890；两条同时满足才算修好。
   修不好就如实写「回归未定位，F1 维持 0.5882，原因待查」，不许用改口径的方式抹平。

## 5. P1 双页对开切分（截图已暴露）

问题证据：《杜工部集》对开页红框显示 ① 左右两页被当一页切，书脊两侧列混排；
② 至少 2–3 处一个框横跨两列；③ 左侧边缘小字被单独框住（夹注未分离）。

1. **书脊检测**：在 `ocr/vertical.py` 增加 `split_spread(img) -> [(x0, x1), ...]`。
   判据：页面中线附近（x ∈ [0.4W, 0.6W]）的垂直投影出现持续低前景带，且宽度 > 页面 3%；
   或用 `cv2.HoughLinesP` 找近垂直长直线。检测不到就返回整页（单页兼容，不许强行切）。
2. **分半页处理**：每个半页独立走「二值化 → 去版框 → 切列 → 列内切块 → 旋转 → 识别」。
3. **阅读顺序**：古籍从右往左翻——**右半页先、左半页后**；半页内仍按 x 从右到左。
   `col_index` 需全局连续编号（右页 0..n，左页 n+1..）。
4. **跨列框抑制**：切列后校验每列宽度分布，若某框宽度 > 1.8× 中位列宽，判为跨列框，
   按该框内垂直投影的次峰再切一刀。
5. **验收**：`page_10.png`（杜工部集）等 3 页人工确认列数正确、无跨列框；跨列框率 < 10%。

## 6. P2 换择优信号（让 P1 真正参与竞争）

1. 现状 `Σ(字数×conf)` 天然偏向字多的整页，逐列一旦漏列就输，34 页全选整页即由此而来。
2. 改用**复合无监督分**（不读 GT）：
   - `合法字符率`：识别字符中落在「繁体模型字符表 ∪ 常用汉字表 ∪ 异体字表」的比例（权重最高）
   - `平均置信度`
   - `列数合理性`：列数落在 [8, 30] 得满分，偏离线性扣分（古籍一页通常 10–20 列）
   - `重复率惩罚`：同一字符连续出现 ≥4 次扣分（乱识别典型特征）
3. 输出每次择优的分数明细到 `notes`，便于复核；`TCM_OCR_VERTICAL_SPLIT=0` 仍可一键回退。
4. **验收**：34 页中逐列至少赢下 8 页，且这些页的 CER 不高于整页结果；若逐列仍然全输，
   说明切列质量不足，回到 P1 修切列，而不是继续调权重。
