## 接入与保守条件

第五轮冻结的 `ocr/small_columns.py`、`ocr/small_columns_hybrid.py`、`ocr/small_columns_components.py`、识别器、版面代码及模型权重哈希未改变。新增 `ocr/small_columns_attach.py`，由 `TCM_OCR_SMALL_COLUMNS=1` 显式启用，默认关闭；配置摘要会报告状态。原整页 OCR 块完整保留，主字、右轨、左轨以带 `small_column_evidence` 类型、父块引用和独立 bbox 的证据块保存。它们排除在正文方剂流之外，避免重抽取和重复药行。

只有同一自动父列与唯一原 OCR 父块相交、两种尺寸识别出的主字一致且高置信、与父块已有的唯一方表药名完全归一化一致、右侧真实墨迹和两尺度识别一致、剂量从右轨开头完整匹配且没有数词残尾、原药行剂量仍为待核，才会更新该既有药行；共享剂量“各”暂不自动分配，已有确认剂量不覆盖，多候选竞争、无证据、异常或无匹配方行均回退。这个判断仍是自动证据，不能当成医学或原文人工校验。规整表所在页跳过该试验路径，保留原有表处理。

原字与炮制信息不被吞入剂量：第 35 页右轨 OCR 为“五錢黃土”，剂量只提取“五錢”，余下“黃土”保留为待核上下文；左轨 OCR 为“排炒”，原图应读作“拌炒”，因此原识别“排炒”及其左轨 bbox 保留并标“待核”，没有自动修正。右侧完整裁块的 bbox 是出处定位范围，**不是逐字剂量框**。

证据块与父块的角色、状态、出处同时写入 JSON 和 SQLite；同页重复处理先替换旧证据块，不删除原块。同一页在隔离库中先启用再关闭：证据块从 6 个变为 0 个，原块保持不变，方表返回基线；重复上传与 SQLite 快照恢复均核对通过。
