### 已定位的三个根因（本阶段要修的就是它们）

1. **对齐口径缺陷（假阴性）**：GT 的 `name` 保留繁体（如 `芍藥`），`value` 归一化为简体（`芍药`）；而 `eval/dataset.py:align_key()` 与 `extract/evaluate.py:align_key()` 均直接用 `(page_id, type, name, value)` 原值对齐，**name 未归一化**。预测基于 `Block.text_norm` 全是简体，于是 `('p0016','药材','芍藥','芍药')` 与 `('p0016','药材','芍药','芍药')` 被判为不等 → 抽对了也算错。FP 中另有空格差异（`一 合` vs `一合`）。
2. **繁体字形识别错误（拖垮 CER 与表格）**：表格**结构正确 2/2**，但单元格内容是 OCR 错字 —— `三兩→三雨`、`生薑→生蕾`、`大棗→大柬`、`芍藥→藥`、炮制 `擘→空`。CER 的 19% 同源。**不是表格算法问题，是识别问题**。
3. **抽取切分粒度不一致**：FP 中 `五脏六腑寒热邪`、`邪气腹痛除血痹` 等片段，对应 GT 的整条主治句 → 规则切分与 GT 粒度不齐。

### 另需修的诚实性问题
- 报告第 12 行「人工抽检 N 页」的 `N` 是未替换的模板变量。
- **可溯源率 1.0 是构造性满分**：`qa/generate.py` 只输出通过 `quote` 校验的证据，自验自证，必然 100%，报告须注明口径局限。
- **拒答率 1.0 口径不全**：只统计了无依据问题，未统计「应答题是否被误拒」。须补「应答题正确作答率」与拒答率配对报告。

## 5. 执行顺序

### P0 对齐口径修正（先做，成本最低、不依赖外部资源）

1. 在 `app/schemas.py` 或 `eval/dataset.py` 增加**唯一**的对齐归一化函数 `align_norm(text)`：去空白与常见标点（复用 `norm_for_match`）→ 异体字表映射（`data/lexicon/异体字表.json`）→ 繁简映射。**`eval/dataset.py:align_key()` 与 `extract/evaluate.py:align_key()` 必须调用同一个实现**，禁止各写一份，避免口径再次漂移。
2. 归一化必须**对称**：GT 与预测走同一函数。禁止只归一化预测、不归一化 GT（那是作弊）。GT 文件里的 `quote` 与 `name` 原文**保持繁体不动**，只在对齐时归一化。
3. 在 `data/annotation/标注指南.md` 第四节写成正式规范：「对齐键统一归一化；GT 原文保留繁体；`quote` 不得改写」。写明这是口径修正而非放宽。
4. 报告必须**双列**：`修正前 0.4375 / 修正后 X`，并注明「差异来自字形等价判定，非模型能力提升」。修正后若仍 < 0.80，如实写未达标。
5. 同时修报告模板：`人工抽检 N 页` 的 `N` 用真实值替换（当前为 0，写「0 页（待办）」）。
6. 补指标：新增「应答题正确作答率」= 应答题中答案正确且证据命中的条数 / 应答题总数；与拒答率成对出现在报告主表。给可溯源率加一行口径说明（构造性达标、自校验闭环）。

**验收**：`python eval/run_all.py` 重跑后报告出现修正前后两组 F1；两组数字都能追到同一批输入文件；`grep` 确认两个 `align_key` 共用同一归一化实现。

### P1 繁体 OCR 精度（本阶段最值钱，直接影响 25 分）

1. **先诊断，不先改代码**。写 `eval/ocr_error_analysis.py`，对 7 个测试页做逐字符对齐统计，产出 `data/reports/ocr_error_analysis.md`：
   - 错字 Top-N 频次表、混淆对（`兩→雨`、`薑→蕾`、`棗→柬`…）、按字频加权
   - 区分三类错误来源：检测漏框 / 识别错字 / 切分错位
   - 繁体字错误占比 vs 简体字错误占比
   - **结论必须回答：主要瓶颈是模型字形能力，还是竖排切图策略？**
2. 按诊断结论选路（两种都要跑 A/B，固定同一批测试页、同一 GT、同一 CER 口径）：
   - **换模型**：RapidOCR 的繁体模型（`chinese_cht`）或 PP-OCRv4 多语言 rec；先读本地包源码/文档确认模型名与调用方式，**禁止凭记忆猜 API**。
   - **改策略**：确认当前是否整页送检；改为按 `bbox` 列聚类 → 逐列切图 → 旋转 90° → 识别 → 坐标反变换回原图。竖排古籍逐列识别通常显著优于整页。
3. **字形纠错层（可解释、可回滚）**：`data/lexicon/异体字表.json` 扩表；新增 `data/lexicon/ocr_confusions.json`（混淆字对，字段含 `from / to / source / confidence`）。纠错只在「上下文可判定」时生效（如与已知药名、剂量单位共现），每次纠错写入 `trace`，可整体关闭（`TCM_OCR_CORRECT=0`）。
4. **禁止**用「改 GT 迎合预测」的方式降 CER；GT 的 `quote` 一字不改。
5. 表格侧不动算法（结构已 2/2 正确），只在识别结果改善后重跑，观察整表正确率变化。

**验收**：CER 降至 **< 0.10**；表格整表正确率 **> 0**；繁体页 CER 单列下降；异体字归一化命中率上升；`ocr_error_analysis.md` 能说清错误来源分布与所选方案的依据。若模型确实换不上（离线/依赖冲突），如实写「方案未生效，CER 维持 0.1911」，**不得编造改善**。
