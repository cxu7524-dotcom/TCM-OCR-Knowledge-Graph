### 2.3 根因（已定位到行）

1. **词典极小**（`extract/schema.py:45-70`）：药材 **11** 个、方剂 **1** 个（`桂枝汤`）、
   功效词 **6** 个、性味模式 13 条。合成页文本是脚本按这些词生成的，所以命中率 100%；
   真实页 OCR 文本里这些词几乎不出现，于是抽取归零。
2. **剂量抽取要求药名在词典内**（`extract/rules.py:187-190`）：真实页药名不在词典 → 剂量也一起抽不到。
3. **默认不加载 v5 模型**：`app/config.py:129` `rec_model` 默认为空，
   `ocr/recognize.py:44-54` 空值直接用 `RapidOCR()` 包内 **简体 ch_PP-OCRv3_rec**。
   真实页 CER **0.4451（v3）vs 0.2287（v5）**，默认路径是双倍错误率。
4. **`is_demo` 写死**（`extract/rules.py:111` 与 `:121`）：所有实体 / 三元组恒为 `is_demo=True`。
   真实页也被标成示例数据；且 `extract/evaluate.py:44-67` 见到 `is_demo=True` 直接拒绝计分。

### 5.2 新增不依赖词典的模式抽取

在 `extract/rules.py` 增加（**顺序与去重逻辑必须确定性，见 `tests/test_extract_determinism.py`**）：

1. **方名模式**：`[\u4e00-\u9fa5]{2,4}(?:湯|汤|丸|散|丹|飲|饮|膏|煎|锭|錠)`
   —— 命中即作为「方剂」候选；命中后**要求该词在本页出现 ≥1 次且不在停用词表**（如「湯」单独、「湯下」不算）。
2. **药名 + 剂量配对（不要求词典命中）**：
   行内匹配 `[\u4e00-\u9fa5]{2,4}\s*[一二三四五六七八九十百半\d]+\s*(?:两|兩|钱|錢|分|枚|升|合|斤|片|勺|盏|盞)`
   → 药名段作为「药材」候选、数字段作为「剂量」。
   **必须保留 `rules.py:187-190` 原有的"词典内"约束作为 `TCM_EXTRACT_DOSE_STRICT` 开关**
   （默认 `0` 放宽，`1` 回到阶段八行为，便于 A/B）。
3. **主治引导**：扩展 `ZHUZHI_RE` 为 `(?:主治|主|治|療|疗)\s*([^，。；、\s]{2,20})`，
   并排除「治之」「治法」「治驗」等非病证短语（做成停用表）。
4. **错字容忍**：对 OCR 文本里与词典项**编辑距离 ≤1 且长度 ≥2** 的片段，
   在 `conf` 低于阈值时尝试匹配，命中记 `extractor="rules_fuzzy"`，**不覆盖原文字段 `quote`**。
   阈值提取到 `app/config.py`（`TCM_EXTRACT_FUZZY=1`，默认开）。

### 5.3 硬约束（不许破）

- 每个实体 / 三元组仍必须带全 `page_id · bbox · line_id · quote · source_hash`，`quote` 一字不改。

- 抽到的低置信结果写复核队列（沿用 `TCM_OCR_MIN_CONF` 的思路），不要静默丢弃。

**验收**：
