本文件只讲**怎么把本仓跑起来、怎么重跑评测、哪些东西不在仓里**。技术方案见

## 一、环境

| 项 | 要求 | 本机实测 |
|---|---|---|
| 操作系统 | Windows / Linux / macOS 均可 | Windows 11 |
| Python | 3.10+ | 3.12.3（仓内 `.venv`）；`requirements.txt` 另注 3.13 实测通过 |
| 算力 | 纯 CPU 可跑，无需 GPU | 8 核 CPU |
| 数据库 | 不需要（本地 SQLite / JSON） | — |
| 网络 | 不需要外网；不调用任何公网推理服务 | — |

检索向量走 `bge-small-zh-v1.5` 本地权重，问答走 `127.0.0.1:11434` 的 Ollama。

## 二、五步跑起来

```bash
# 1) 取代码
git clone <仓库地址> TCM-OCR-Knowledge-Graph
cd TCM-OCR-Knowledge-Graph

# 2) 建虚拟环境（Windows 用 .venv\Scripts\python.exe）
python -m venv .venv
.venv\Scripts\python.exe -m pip install -U pip          # Windows
# .venv/bin/python -m pip install -U pip                # Linux / macOS

# 3) 装依赖（约 5 分钟，含 OCR 的 onnxruntime）
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 4) 起服务（会自动挑空闲端口，默认 8100）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1
#  装了 PowerShell 7 也可以： pwsh -File scripts\start.ps1
#  不想用脚本就直接： .venv\Scripts\python.exe app\main.py --port 8100
#  Linux/macOS： sh scripts/start.sh
```

起来后三个页面：

| 路径 | 页面 | 看什么 |
|---|---|---|
| `/` | 四步演示台 | 上传古籍页 → 识别与结构化 → 图谱可视化 → 可溯源问答；页首有实测指标带，页末有评测概览 |
| `/home` | 智能问答 | 大模型问答、三档模式、出处、语音输入 |
| `/lounge` | 聊天室 | 官方四间 + 游客自建、邀请、引用/@/未读、成员角色、公告历史、文件、问 AI 中医师 |

### 起服务后先自检

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\smoke.ps1 -Port 8100
# PowerShell 7： pwsh -File scripts\smoke.ps1 -Port 8100
```

七项只读检查（三页 200、/api/metrics 有指标、语义索引有向量、聊天室有官方房、空问题被拒答），
全 PASS 即环境正常；有失败会打印原因并以退出码 1 结束。

### 大模型（可选）

```bash
ollama pull qwen2.5:7b     # 一次性，约 4.7 GB
ollama serve               # 默认已在 127.0.0.1:11434
```

不装也能跑：`/api/qa` 会退回字面检索链路，界面如实显示「当前为字面检索」，不会假装有大模型。
若要走纯规则链路，起服务时加 `-NoLlm`（Windows）或 `TCM_LLM_BACKEND=none`（通用）。

python eval/run_all.py              # 缺预测则自动生成，然后算分
python eval/run_all.py --refresh    # 强制重跑 OCR / 抽取 / 问答，再算分

产出（幂等覆盖）：

- `data/reports/评测明细.json`：机器可读明细，`/api/metrics` 与演示台指标带都读它（**已入库**）

本次结果（**合成示意集 · 工程自测 · 非命题单位样本 · 非官方评测结果**）：

| 指标 | 实测 | 赛题要求 | 判定 |
|---|---|---|---|
| 字段级 F1 | 0.8283 | ≥ 0.80 | 达标 |
| 方剂表结构还原 | 1.0000 | 可用水平（本工程口径 ≥ 0.80） | 达标 |

## 六、仓里的三个脚本

| 文件 | 用途 | 说明 |
|---|---|---|
| `scripts/start.ps1` | Windows 一键启动 | 自动挑空闲端口（8100 → 8000 → 8101-8103）、设 `PYTHONUTF8` 与 Ollama 环境变量、优先用 `.venv`；`-Port` / `-NoBrowser` / `-NoLlm` 三个开关 |
| `scripts/start.sh` | Linux/macOS 一键启动 | 同上，端口用 `TCM_PORT` 覆盖，不开浏览器 |
| `scripts/smoke.ps1` | 起服务后自检 | 七项只读检查；全 PASS 退出码 0，便于脚本化验收 |
| `scripts/faults.py` | 故障自检（负向） | 13 个「本来就该被拒绝」的用例，查状态码与中文文案；限流用例会临时建房并自动删除。`python scripts/faults.py --port 8000` |

两个 `.ps1` 均按 Windows PowerShell 5.1 兼容写法，并以 UTF-8 **带 BOM** 保存（5.1 读无 BOM 的中文脚本会报语法错）。

各类故障（模型没起、索引缺失、OCR 依赖缺失、上传超限、发言限流……）的实测表现，见[故障演练](故障演练.md)。

## 七、常见问题

**端口被占**：`start.ps1` 会依次试 8100 / 8000 / 8101-8103；也可 `-Port 8123` 或 `set TCM_PORT=8123`。
控制台会打印 `[note] 8100 已被占用，改用 8000`。

**看起来起来了但页面空白**：先 `powershell -NoProfile -File scripts\smoke.ps1 -Port <端口>` 看是哪一项失败；
常见是端口写错（服务在 8000、你开了 8100）或反向代理改了路径。

**脚本被拦（ExecutionPolicy）**：`start.ps1` / `smoke.ps1` 未签名，组策略较严时会拦。
用 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1` 即可；或直接跑
`.venv\Scripts\python.exe app\main.py --port 8100`（脚本只是包了端口挑选与 env 默认值）。

**Linux/macOS 起不来**：`start.sh` 需要 `bash` 或 `dash`；若提示 permission denied，用
`sh scripts/start.sh` 而不是 `./scripts/start.sh`。

**问答说「暂时不可用」**：Ollama 没起或模型没拉。`ollama list` 确认有 `qwen2.5:7b`；
也可以 `-NoLlm` 起服务，用规则链路验证其余功能。

**上传报 400 / 413**：只接受 png/jpg/jpeg/bmp/webp/tif；单页上限见接口提示（413 为超限）。
上传件只落本机 `data/uploads/`，不出网。

**Windows 控制台中文乱码**：`start.ps1` 已设 `PYTHONUTF8=1`；直接跑 `app\main.py` 时请先
`chcp 65001` 或 `set PYTHONUTF8=1`。

**评测数字和报告不一致**：`data/reports/*.jsonl` 是上一次跑批的预测；用 `--refresh` 强制重算。
数字只认 `评测明细.json` 里的分子分母，界面与报告都从它来。
