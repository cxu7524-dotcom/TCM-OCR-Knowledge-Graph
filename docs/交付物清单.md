## 二、技术报告建议结构（与评分权重对齐）

1. 赛题理解与方案匹配度（对应「方案匹配度与创新性」）
2. 系统架构：四步链路、数据契约、溯源五元组、本地化部署（对应「工程实现与可复现」）
3. OCR 与版面还原：竖排列聚类、碎片合并、繁简异体、方剂表结构还原（30 分）
4. 抽取与知识图谱：实体/关系口径、图谱构建与查询（10 分）
5. 可溯源问答：混合检索、证据强约束、拒答边界（25 分）
6. 实测与评测：五项指标、阈值判定、未达标分析与改进计划（关键指标实测可验证）
7. 数据合规与保密（本地化、零公网、样本不外传）
8. 局限与阶段三计划（本地 LLM、语义向量、命题样本实测）

## 四、验收口径（自检清单）

- [ ] 报告中每个指标值都能追到 `data/reports/评测明细.json` 的分子/分母与 GT 版本哈希
- [ ] 合成集与命题样本结果**分列**，显著位置标注「非官方评测结果」
- [ ] 未达标项如实列出原因，无美化、无改写 GT、无放宽 quote 校验
- [ ] 视频分辨率 ≥1920×1080、时长 ≤5 分钟、含三部分内容
- [ ] 工程 `pip install -r requirements.txt` 后 `python app/main.py` 可起，`python eval/run_all.py` 可重跑
- [ ] 全库无公有云调用、无 API Key 读取，`TCM_LLM_BACKEND` 默认 `none`
- [ ] 样本合规材料齐全（授权、脱敏、销毁）
