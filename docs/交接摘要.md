## 本地启动与复现

Windows PowerShell，在项目根目录运行：

```powershell
# 首次准备环境
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动网页
.\.venv\Scripts\python.exe app\main.py

# 另开终端运行全量单测
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

网页 [127.0.0.1:8000](http://127.0.0.1:8000/)，接口文档 [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)。也可双击 `启动操作台.bat`。项目验证环境为 Python 3.12。OCR 默认探测 `模型权重/ch_PP-OCRv5_rec_mobile.onnx`，缺文件时会退回依赖包内模型。复现实验前用 `/api/health` 确认实际模型。浏览器验收脚本位于 `output/qa_verify5/scripts/`。历史上传页号仅用于查找留存记录，重新上传需使用当次页号。

合成页可用 `tools/make_synthetic_pages.py` 重建。`eval/run_all.py --refresh` 会重写本地预测和报告。做对照时先留存原始预测、模型配置和 GT 版本，将不同运行的产物保存到独立目录。安装说明与其他接口见 [README](../README.md)。
