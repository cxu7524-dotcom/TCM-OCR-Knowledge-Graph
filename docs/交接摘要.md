## 6. 关键配置（`app/config.py`，环境变量 `TCM_` 前缀）

| 变量 | 默认 | 说明 |
|---|---|---|
| `TCM_OCR_BACKEND` | `rapidocr` | 本地 ONNX，CPU，模型随包分发 |
| `TCM_OCR_REC_MODEL` | 空 | 空=包内简体 v3；**推荐** `模型权重/ch_PP-OCRv5_rec_mobile.onnx` |
| `TCM_OCR_VERTICAL_SPLIT` | `1` | 竖排逐列 + 双页切分；`0` 完全回退整页 |
| `TCM_OCR_PICK` | `auto` | `auto` 复合分择优 / `vertical` 强制逐列 / `page` 强制整页（A/B 用） |
| `TCM_OCR_PICK_MARGIN` | `1.02` | 逐列分需 > 整页分 × 该余量才改判；放到 1.00 会让 3 页改判但有 1 页明显劣化，见阶段五报告 |
| `TCM_OCR_CORRECT` | `1` | 字形纠错层；`0` 整体回滚 |
| `TCM_OCR_MIN_CONF` | `0.35` | 低置信过滤（低于阈值写复核队列） |
| `TCM_OCR_ROTATE` | `90` | 90=逆时针（实测有效） |
| `TCM_LLM_BACKEND` | `none` | 阶段三~五均未启用，`is_local()` 硬拦截非本机 |
| `TCM_VECTOR_ENABLED` | `0` | 语义向量未启用（hash 占位，非语义） |

## 7. 已踩过的坑（别再踩）

1. **中文路径**：`cv2.imread` 读不了 `古籍评测集/*.png`，统一 `cv2.imdecode(np.fromfile(...))`。
2. **处理顺序**：`layout 合并 → 表格补格 → 字形纠错 → 归一化 → 表格还原`。顺序错了 `text_norm` 会被覆盖。
3. **纠错词边界**：药名近形字纠错必须限制在词边界，否则「味甘平」会被纠成「味甘草」。
4. **问答匹配键**：应答题作答率必须用 `(question, page_id)` 复合键。
5. **表格补格异常**：必须局部降级，不能让异常冒泡到 `run_ocr`。
6. **CER 口径**：`编辑距离/GT字数`，只去标点空白，**不做繁简归一化**；别用 `1-SequenceMatcher.ratio`。
7. **对齐口径**：唯一实现在 `app/schemas.py:align_norm()` / `entity_align_key()`；GT 与预测必须**对称**归一化。
8. **指标抖动先查可复现性**：阶段五 F1 在 0.5882/0.6471 之间跳，真因是 `extract/rules.py` 依赖 set 迭代顺序
   （PYTHONHASHSEED 随机）。凡见「同输入不同输出」，先跑两个种子再谈回归；已用
   `tests/test_extract_determinism.py` 锁死。
9. **`_remove_lines` 会吃掉宽横笔画**：横向开运算核 `max(40, w//25)` 会把宽列里的长横笔当版框减掉。
10. **两路择优前都要先做低置信过滤**：整页 raw 输出 CER 0.89，过 `min_conf=0.35` 才 0.29，不先过滤对比不公平。
11. **块数指标已作废**：按列整列识别时块数≈列数，与质量无单调关系；用列数准确率 + 跨列框率替代。
12. **git 身份**：仓库本地已配 `cxu7524-dotcom`，直接 `git commit`；禁止 `push --force`。
