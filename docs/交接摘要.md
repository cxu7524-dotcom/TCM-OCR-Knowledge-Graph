## 7. 已踩过的坑（别再踩）

1. **中文路径**：`cv2.imread` 读不了 `古籍评测集/*.png`，统一 `cv2.imdecode(np.fromfile(...))`。
2. **处理顺序**：`layout 合并 → 表格补格 → 字形纠错 → 归一化 → 表格还原`。顺序错了 `text_norm` 会被覆盖。
3. **纠错词边界**：药名近形字纠错必须限制在词边界，否则「味甘平」会被纠成「味甘草」（已修，有注释）。
4. **问答匹配键**：应答题作答率必须用 `(question, page_id)` 复合键，单键会串页（0.28 → 0.91）。
5. **表格补格异常**：必须局部降级，不能让异常冒泡到 `run_ocr`（否则整页降级成 demo 数据）。
6. **CER 口径**：`编辑距离/GT字数`，只去标点空白，**不做繁简归一化**；别用 `1-SequenceMatcher.ratio`（值会差 3–5 个点）。
7. **对齐口径**：唯一实现在 `app/schemas.py:align_norm()` / `entity_align_key()`，两个 `align_key()` 都是委托；GT 与预测必须**对称**归一化。
8. **git 身份**：仓库本地已配 `cxu7524-dotcom`，直接 `git commit` 即可；禁止 `push --force`。
