## 失败分析与可复现证据

对 23 条真实漏提，以人工转写对照作互斥归类：**10 条在人工转写上已未命中**，属于现有切段／药量抽取或出处匹配的缺口；**13 条人工转写命中但真实上传未命中**，说明真实 OCR 文本或顺序变化影响了端到端结果。该分类是对照观察，不证明两类原因互斥或构成严格因果实验。

- **配伍抽取本身**：37 页四物湯人工转写中“揀芍二錢半”未形成对应药味行，“大熟地”被缩成“熟地”；39 页三味均带“自……可以加至……”范围，人工转写输出的剂量均为待核；50 页“白芷、川芎各一錢蒼朮”跨块分配不完整。这 10 条即使不考虑 OCR 也未完整命中。
- **OCR 字形及方名**：50 页 R014 将共享剂量的“各”识成“洛”，桂枝／芍藥／生薑三行剂量待核；R002 将“九味羌活湯”识为“九味活湯”，即使其后三个药量正确，方名仍不满足整行命中。41 页 R016 的人參、白朮、干薑及剂量发生严重错漏，R015“一錢半”末字识成“牛”。
- **错误切段与转引**：40 页 R016 的煎服语“不加引水煎温服”被识成方名“不加引水煎”，其后药理论述中的山藥、茯苓误出两行；该页 GT 为 0 行。41 页“卽前方加川附子製一錢半”的转引被误作附子理中湯新方，出两行“附子”，第二行甚至来自后方论述 R010／R009。两行均计误出。
- **阅读顺序**：五页主要题名与配伍块的右至左顺序可从原始 JSON 的 `reading_order` 和 bbox 复查；但 37 页版口 R001、50 页零碎 R021 排在正文末尾，不能视为干净正文。41 页“附子”恰好跨 R010／R009 被拼入前方，说明相邻块连接与段落边界也可能把方论误归为组成。
- **方名／剂量归属**：50 页九味羌活湯的生地、細辛、甘草虽然显示可读剂量，但所属显示方名“九味活湯”不符，故三行都不算命中。2 条真实命中仅为 50 页桂枝湯的甘草二錢、大棗二枚，药材和剂量均回到 R013，方名回到 R003。
