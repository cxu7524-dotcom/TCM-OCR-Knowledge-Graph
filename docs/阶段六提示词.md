### 2.2 已确认的 GT 口径缺陷（本阶段必须正面处理）

`label.csv` 的 `OCR` 列是**正文转写**，不是整页全部文字：

- `思濟堂方書/page_30.png`：双页对开，**右半页全是背面透印**，GT 只转写左页正文（142 字）
- `丹方彚编/page_2.png`：书名页 + **手写行书序**，GT 只转了书名页 121 字

后果：模型识别出页眉、版心、透印、朱印、手写序，**全部算插入错误**，CER 被系统性抬高。
这可能是阶段五医家类 CER 0.419 偏高的一部分原因，**不全是模型能力问题**。

## 5. B. 对开判定核验（6 页人工确认）

1. 每部书抽 2 页（含 `丹方彚编/page_2`、`思濟堂方書/page_30`），调用 `ocr/vertical.py:page_layout()`，
   记录「判为单页 / 判为对开」与切出的列数。
2. 人工看图核对是否真的对开（左右版框 + 书脊）。
3. 若宽高比 1.09–1.16 的对开页被误判为单页：
   - **不许用 GT 调参**，只能用物理先验（左右两个独立矩形版框、中缝暗带、两半各 ≥3 列）补判据。
   - 改动记入报告，并在 6 页上重验。
4. 验收：6 页判定结果列表 + 误判数；误判未修好也要如实写，不许静默忽略。

## 6. C. GT 口径：双口径报告（本阶段最关键的判断）

**硬约束：不改 GT、不放宽 CER 口径、不挑页、不删失败页。**

1. 主指标保持现有严格口径：`CER = 编辑距离(norm(pred), norm(GT)) / len(norm(GT))`。
2. 增加两个**辅助诊断量**（只用于解释，不替代主指标、不参与达标判定）：
   - `覆盖率` = pred 中能在 GT 内匹配的字数 / pred 长度（现有）
   - `插入率` = `(len(norm(pred)) - 匹配字数) / len(norm(GT))`
     —— 区分「认错了」与「多认了（页眉/透印/印章/手写序）」
3. 报告新增「GT 口径声明」章节，说明：
   - 本数据集 GT 为**机器转写、只覆盖正文**，非人工逐字校对、非命题单位样本；
   - 因此 CER 含「合理识别但不在 GT 内」的插入错误，**会系统性偏高**；
   - CER 必须与覆盖率、插入率**三者配对解读**，禁止单独引用 CER 下结论。
4. 抽检 10 页做「多余文字归因」：把 pred 中未匹配 GT 的片段导出，
   人工归类为「页眉/版心 / 透印 / 朱印 / 手写序 / 真错字 / 其他」，给出各类占比。
   归因结果只写进诊断章节，**不回写主指标**。
5. 验收：报告同时给出 CER / 覆盖率 / 插入率三列；10 页归因表可查；
   主指标数值与直接跑 `eval_guji.py` 的结果**完全一致**（不许"修正"）。
