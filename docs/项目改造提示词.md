## 7. 关键数据契约（`app/schemas.py` 必须定义）

|   |   |   |   |
| - | - | - | - |

- `Block`：`page_id, bbox[x1,y1,x2,y2], line_id, col_id, reading_order, text, text_norm, kind(paragraph|table_cell|title|dose), conf, source_hash`  
  |  |  |  |  |  |  |  |  |  
  | --- | --- | --- | --- | --- | --- | --- | --- |
- `Entity`：`name, type(药材|性味|归经|功效|主治|禁忌|方剂|剂量), value, block_ref, quote, source_hash`
- `Triple`：`head, relation, tail, evidence_refs[], source_hash`
- `Evidence`：`quote, page_id, bbox, line_id, score, source_hash`
- `Answer`：`text, evidences[], refused:bool, refuse_reason, disclaimer, trace[]`

任何模块返回缺字段的数据视为 bug；`qa/generate.py` 输出前必须校验每条 `Evidence` 的 `quote` 能在 `Block.text` 中命中，否则转拒答。
