# 步骤 5：剩余错误与 PP-OCRv5 server 对照

## 决定

接入官方 PP-OCRv5 server **作为可选的小字右轨局部回退**；整页和主字仍用原 mobile 模型。固定集 11 个可读剂量片段按步骤 1 单块归一化包含口径：mobile 小字方案 **6/11**，选择性 server 回退 **8/11**。新增 P39-02 和 P34-11 的片段命中，没有丢失原有六项；这些新增证据仍标“待核”。在这八个固定页的完整方表重放中，mobile 和选择性回退都没有新增确认剂量，因而本次没有新增错误确认；**完整正确方表行仍为 0/11**。没有新增确认也意味着不能据此推断未见页面上的误确认率。

两项开关均默认关闭：`TCM_OCR_SMALL_COLUMNS=1` 启用步骤 4 小字接入，另设 `TCM_OCR_SMALL_COLUMNS_SERVER=1` 才允许 server 回退。仅当 mobile 右轨不能从开头解析剂量或任一尺度置信度低于 0.8 时，才尝试 server；server 原始和 2 倍尺度须一致、各自置信度至少 0.8 且开头有可解析剂量。仍须通过步骤 4 的真实墨迹、同父列、唯一药名归属、未确认剂量、共享剂量不自动分配等全部门禁。剂量后有不明尾字或数词残留时回退待核；权重缺失或摘要不符时保留 mobile。server 证据单独记录模型名、父块引用及 bbox，可定位原图。整页 OCR、原始块、规整表和步骤 3 冻结几何均不被替换。

## 固定输入和来源

固定集此前反复查看过，不是独立盲测。先冻结 11 个样本对应的第五轮自动裁框、人工参考框和新书页人工诊断框及 SHA-256；两模型始终读取同一无损原图裁块，用同一 RapidOCR 识别器、逆时针 90 度旋转，分别运行原尺度和双三次 2 倍尺度。标签只用于推理后匹配和评分。人工参考框、新书人工框均不计入自动成绩。

server 权重来自 [PaddlePaddle 官方 PP-OCRv5 server ONNX 仓库](https://huggingface.co/PaddlePaddle/PP-OCRv5_server_rec_onnx/tree/main)，SHA-256 为 `d9dc333c9c7b042c6dffb8e33d72b6f65c9c1d463d0a3c2f78174fea55e94752`（84,503,027 字节）；本地 mobile SHA-256 为 `5825fc7ebf84ae7a412be049820b4d86d77620f204a041697b0494669b1742c5`（16,631,306 字节）。server 官方字符表与 mobile 内嵌的 18,383 项完全一致，两者输入尺寸均为 `[3,48,320]`。官方模型包与字典另存于 `模型权重/PP-OCRv5_server_rec_official.onnx` 和 `PP-OCRv5_server_rec_official.keys.txt`。

对照在 `output/small_columns_step5/runtime` 独立虚拟环境执行，只读引用项目现有依赖，没有改装项目环境；两者均为 ONNX Runtime CPU，同进程各预热一次。固定样本的 30 个自动子框、2 倍尺度单次识别中位数：mobile **12.24 ms**，server **36.07 ms**；均值分别 12.66 / 37.63 ms。此为裁块识别时间，不含整页版面、关联或 API 时延。

## 几何、文字及归属拆解

固定 11 例中，第五轮自动几何 **1 例未产生匹配框**（P34-10），另外 **2 例主字框严格目视未通过**（P46-08、P50-09）。对同一自动右轨框，仅看 2 倍尺度完整剂量片段，mobile 为 **6/11**、server 为 **7/11**：server 修复两项但使一项退化。选择性回退保留 mobile 在 P50-09 的识别，因此得到 **8/11**，仍仅是待核识别片段。
