## 4. P1 竖排逐列检测（核心，必须做）

### 4.1 新增 `ocr/vertical.py`

```python
def ocr_column(crop, max_h: int = 1400) -> list[dict]:
    """列内切块 + 旋转 + 识别。返回 [{text, conf, bbox_in_col, bbox_in_page}]。"""
```

### 4.2 处理流程（顺序不能颠倒）

1. **预处理**：灰度 → 自适应二值化（`cv2.adaptiveThreshold`，blockSize 奇数、C 取小值）→ 去椒盐噪点。
   保留原图，二值图只用于**找列边界**，不用于识别（识别用原图裁剪，避免丢笔画细节）。
2. **去版框**：检测最外层长直线（`cv2.HoughLinesP` 或形态学开运算），把版框内缩若干像素，
   避免把边框当成一列。
3. **列分割**：对二值图做**垂直投影**（每列黑像素计数），找连续低于阈值的「谷」作为列间隙；
   过滤宽度 < 20px 的碎片（噪点/界行），过滤高度 < 页面 20% 的列（页眉页脚）。
4. **阅读顺序**：古籍竖排**从右向左**。按 `x_center` 降序给 `col_index`（最右为 0）。
5. **列内切块**：对每列做水平投影，按字间隙切块；单块高度超过 `max_h` 时按比例再切，
   避免 rec 输入过长被截断。
6. **旋转**：竖排列高宽比 > 2 时旋转 **90° 顺时针**（`cv2.ROTATE_90_CLOCKWISE`），
   使字正立、阅读方向变为从左到右。**必须实测确认方向**：先用 3 页分别试 90° 与 270°，
   取识别字数多、字符合理的方向，把结论写进注释。
7. **识别**：调用 `ocr/recognize.py:recognize_crop()`（内部 `engine.text_recognizer`），
   不要另写模型加载。
8. **坐标反变换**：旋转后的 bbox 必须映射回**原图坐标系**再写入 `Block.bbox`。
   顺时针 90° 的映射公式写清楚并加单元测试（`tests/test_vertical.py`）。
9. **拼接**：按 `col_index` 升序（右→左）、列内按 `bbox_in_col.y` 升序拼接整页文本。

### 4.3 接入与回退

- `ocr/pipeline.py:run_ocr()`：在 `recognize()` 之前判断 `is_vertical_page()`，
  竖排走 `split_columns` + `ocr_column`，横排保持原整页识别。
- `app/config.py` 新增：`TCM_OCR_VERTICAL_SPLIT`（默认 `1`）、`TCM_OCR_COL_MIN_W`（默认 20）、
  `TCM_OCR_COL_GAP_RATIO`（默认 0.02）、`TCM_OCR_ROTATE`（`90`/`270`，默认 `90`）。
- **必须可一键回退**：`TCM_OCR_VERTICAL_SPLIT=0` 时行为与现在完全一致，便于 A/B。
- `ocr/layout.py` 保留，但改为**消费**列结构（若 vertical 已给出 col_id，就直接采用，不重复聚类）。

### 4.4 已知难点（允许标 TODO，但不许假装解决）

- 双行小字夹注：先按整列识别，标注 `kind="annotation"`，不做精细分离。
- 界行（列间细竖线）容易被当成窄列：靠宽度过滤 + 版框内缩处理。
