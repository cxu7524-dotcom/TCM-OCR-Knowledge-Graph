# 步骤 5：网页展示与原图回跳验证

## 本轮实现

在现有 `app/web/index.html` 的“识别与结构化”页，方剂区按 OCR 阅读顺序同时显示所有结果。正文一方一表，方名为可点击表头，药材和剂量逐味显示；每表标明“正文抽取”或“原书表格”，表尾状态“可能续页”可见。页首续方提示也可查看原文。原书表格继续按原有网格和单引用规则展示。

正文点击使用接口的 `field_details` 和 `cell_refs_multi`，核对同页引用、原始文本半开区间及 bbox 后同时高亮所有来源块。待核、原文未载若只有配伍上下文，则标明“查看上下文”，不把上下文伪称为剂量原文；详情显示各块 OCR 文本。无可验证出处时不沿用旧高亮。Enter／空格可操作表格单元格。原文索引按 Unicode 字符处理，避免扩展汉字导致范围错位。

### 受控浏览器输入

隔离服务生成一张**合成图**并预置与之对应的受控 OCR，不作为真实扫描或 OCR 准确率证据。桂枝湯的桂枝与甘草共享剂量，原文“各三／錢”被构造成 R003 `[530,130,580,230]`、R004 `[460,130,510,185]` 两块。浏览器分别实点两行剂量格，两次均高亮相同的 R003、R004；键盘 Enter 也得到相同结果。稀涎散“原文未载”格实点定位 R007 配伍上下文；四君子湯显示“可能续页”。截图：`controlled_shared.png`、`controlled_tables.png`。

## 仍待核实

真实 OCR 在 page_35 仍将部分药名与剂量识错，因此页面正常展示多个“待核”，本轮不声称准确率达标。受控样例只验证多块、共享剂量及状态交互；混合正文／原书规整表的识别质量仍受步骤 4 版面聚类限制。正式固定验收页留待步骤 6。
